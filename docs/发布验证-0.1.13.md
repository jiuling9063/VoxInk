# 0.1.13（15）发布验证

日期：2026-09-27。目标发行方式：Developer ID 签名、Apple 公证的 macOS arm64 DMG，经 GitHub 正式 Release 分发。最低系统 macOS 15。

## 本次变化

- 首次准备改为场景选择、权限与模型准备、远程配置、固定文字测试、语音测试的分步引导。
- 本机流程跳过远程配置；远程及两者都用流程验证当前远程会话。
- 必须由用户核实目标实际收到正确文字，不以“已发送粘贴”代替接收确认。
- 支持稍后继续、保存进度、重新运行；保留旧版完成标记。
- 远程配置变化使已有测试确认失效，提供失败排查及手动复制路径。
- 四种翻译及引导回归测试同步更新。

## 已知问题与边界

- UU 远端额外语音浮窗仍出现；经用户确认新增 Option+Shift+Space 仅控制端响应规则后仍复现。关闭浮窗时远端菜单显示 Cindy，具体冲突机制仍待查。文字成功写入不代表此问题已修复。
- 引导测试步骤可能显示上一阶段的权限提示；部分系统的权限页名称已改为“设备控制和数据访问”。
- 同步确认文案尚未兼容所有默认同步、没有独立开关的远程工具，安装指南补充了实际复制粘贴验证办法。
- 未全面验证其他远程客户端、Windows、全屏模式、干净机器首次下载和长期使用；未替换用户当前安装的 App。
- 未改动模型、润色运行时及粘贴核心逻辑；前版 Python 与离线润色测试不冒充本版重新执行的结果。
