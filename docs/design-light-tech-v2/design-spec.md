# 雾光细化 v2

用户反馈：雾光整体感觉可以，需要更精致、光感更强；HUD 不要太大，提高透明度，视觉轻盈，并有光效互动。

## 本轮调整

| 项目 | v1 雾光 | v2 雾光 |
| --- | --- | --- |
| 常态 HUD | 约 370 × 80 | 约 304 × 64，面积减少约 34% |
| 玻璃底色 | 95% 不透明度 | 72% 不透明度，即 28% 透明度 |
| HUD 外形 | 22 圆角，较深远的投影 | 19 圆角，更短更柔的投影，细亮边 |
| 窗口层次 | 均匀磨砂 | 增加上缘光、细腻底色渐变与按钮内高光 |
| 录音光效 | 动态声波 | 声波和底缘光共用示例声量参数 |
| 识别 / 完成 | 声波呼吸 / 静态结果 | 边缘缓慢呼吸 / 短暂亮起后收拢 |
| 悬停 | 按钮反馈 | HUD 内局部光晕跟随指针，不旋转或移动窗口 |

尺寸以页面 CSS 像素、100% 缩放为参考，不能代替原生 pt 实测。失败状态仍可增高以容纳恢复操作，正文不裁切。窄屏保留取消按钮，优先隐藏非必要计时显示。

透明度调整的是玻璃背景色，不降低整块 HUD 或文字的不透明度。调节范围 12%–36% 透明度；深色文字区保留轻微遮罩，文字使用明亮灰白。支持减少透明度偏好和不支持模糊时的实色回退。复杂桌面背景上的实际对比度仍需视觉确认。

## 查看方法

打开 `index.html#hud-section`，默认 A 雾光。播放完整流程，或停留在单个状态；调整示例声量、透明度以及桌面背景。鼠标经过 HUD 查看局部光效。顶部可切换减少动态，系统减少动态偏好也会禁用光效运动及指针追随。

“示例声量”不是麦克风数据；当前光效用于设计评审，原生实现需绑定真实音量和真实状态。原生 HUD 继续保持不激活、不抢输入焦点，悬停感应不能引入焦点切换。失败与取消的语义沿用已验收原型。

## 文件与复核

- `index.html`：可直接离线打开，图像、样式和脚本均内嵌。
- `refinement.css` / `refinement.js`：本轮样式与交互增量源码。
- `build-preview.py`：在保留的 v1 基础上生成 v2，不修改 v1。
- `verify-preview.cjs`：静态结构与模拟 DOM 状态检查，新增光感参数、指针边界和减少动态行为检查。

```sh
python3 docs/design-light-tech-v2/build-preview.py
node docs/design-light-tech-v2/verify-preview.cjs
```

当前仅为设计迭代，尚未应用到 App。Logo 沿用 v1 内嵌概念，本次未重新生成位图；旧的生成概念板不能代表 v2 外观。完整品牌规范及未完成范围参见 [v1 规范](../design-light-tech-v1/design-spec.md)。

浏览器工具此前阻止自动访问本地演示文件，因此不绕过策略执行浏览器渲染；此次可验证脚本逻辑，视觉、真实鼠标交互、模糊合成与无障碍效果由页面评审及后续原生验证确认。

本轮复核结果：生成成功；原有流程与新增声量、透明度、背景、指针光效边界、页面/系统减少动态的模拟 DOM 检查全部通过。这不代表浏览器视觉验收完成。
