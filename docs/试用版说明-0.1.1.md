# 语落 VoxInk 0.1.1 邀请试用版

发布包标识：0.1.1-trial.3。App 版本 0.1.1，构建号 3。

本版本已完成 Developer ID 签名，Apple 公证审核状态为 Accepted。默认安全设置下的外部安装与跨设备首次运行仍待验证。

## 本批变化

- 接通转录引擎、快捷键与输入、后处理、润色模型和使用方法五个侧栏页面。
- 主窗口与偏好设置共用设置逻辑；后处理页可管理用户词典。
- 修正录音准备状态，模型和麦克风未就绪时不显示“可以开始说话”。
- 紧凑录音浮层在失败时提示打开语落查看详情。

## 安装与更新

需要 Apple Silicon Mac、macOS 15 或更高版本。退出旧版后，打开 DMG，将 VoxInk 拖入“应用程序”并替换旧版，从同一位置启动。首次使用按界面提示下载约 713 MB 的识别模型，并允许麦克风；自动写入还需要辅助功能权限。

升级后先查看仪表板的权限与模型状态。若系统要求退出重开，请照做。不要通过关闭系统安全功能处理启动问题。

## 建议验证

1. 在文本编辑器的空白文档中录一句不含隐私的短句，确认只写入一次。
2. 录音时仍按住快捷键，再按 Esc 并松开，确认不写入；随后再录一句检查恢复。
3. 修改快捷键模式，确认侧栏和偏好设置同步；退出重开后确认设置保留。
4. 检查睡眠唤醒、连续录音，以及常用应用中的输入兼容性。

已写入文字需在目标应用中撤销，Esc 不负责撤回。自动测试和开发机验证不能替代另一台 Mac 的首次安装测试。

## 隐私与限制

识别在本机进行，首次下载模型需要网络。润色组件另行安装，本包不包含；启用润色只开放手动预览，不自动覆盖或写入原文。姓名、数字和润色结果请自行核对。

请使用随包反馈模板记录系统版本、操作步骤和结果，无需提交私人录音、聊天内容或凭据。本版本没有自动升级安装流程。
