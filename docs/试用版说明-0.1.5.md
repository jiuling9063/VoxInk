# 语落 VoxInk 0.1.5 邀请试用版

App 0.1.5，构建 7。适用于 Apple Silicon Mac、macOS 15 或更高版本。

## 本次更新

- App 内置独立的 Python/MLX 润色运行组件。全新设备无需安装 Python、Homebrew、uv 或手动配置环境。
- 在「润色模型」点击「下载并启用」，App 自动检查组件、下载并校验模型、进行一次离线试运行；全部通过后开启润色。若下载期间开始了录音等任务，可在任务结束后开启。
- 安装显示准备、下载校验和运行验证三个阶段。失败或取消可重试，部分下载会保留；未经运行验证的新模型不会显示为已就绪。
- 模型权重继续按需下载，不随 App 打包；旧版已安装模型和用户设置继续复用。

## 安装与首次使用

退出旧版，打开 DMG，将 VoxInk 拖入「应用程序」并替换旧版，再从「应用程序」启动。

首次使用需要联网下载转录模型；本地润色为可选功能，可在「润色模型」点击「下载并启用」。润色模型默认从 Hugging Face 的固定版本下载。首次下载仍需能够访问模型下载服务；安装好后，转录与润色在本机运行。App 内置运行组件，无需用户另行配置环境。

按提示允许麦克风；自动写入还需要辅助功能权限。先点选目标输入框，再使用设置中显示的快捷键。窗口内录音与导入仅展示结果。

## 本地润色

新用户默认关闭自动润色。点击「下载并启用」并成功验证后开启；升级保留已有设置。自动选择仅使用已安装模型，不自动下载其他档位、不调用云端。润色超时或内容校验失败时使用未润色文字，并保留识别原文。

## 验证范围

发布前检查独立运行组件的搬迁、原生依赖与 Metal 运算，并以独立空目录验证真实模型下载和离线润色。该测试在开发机的隔离目录完成；其他实体 Mac、不同 macOS 版本及网络条件仍需试用验证。

验证通过 247 项常规 Swift 测试、62 项 Python 脚本测试及 1 项真实下载与润色集成测试。另在禁止联网、禁止读取旧版润色环境和开发机工具目录的条件下，验证搬迁后的正式 App 能独立完成润色。

反馈时请使用 [试用反馈模板](试用反馈模板.md)，不要附上包含隐私的录音或输入内容。
