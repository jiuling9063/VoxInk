# 温润书写 V2 · 深化基线

用户已选择 `assets/logo-rain-impression-v2.png` 作为温润书写方向的深化基线。本轮锁定它的一大一小双形、内卷纸感与浅雾青气质，不再继续换 Logo；工作范围是把同一语言扩展到主窗口、设置、HUD、深色和辅助功能。轻盈科技 v4 保留，不修改；原生 App 也暂不改动。

## 核心判断

V2 不走古风笔墨，也不追求明显的玻璃科技感。它更像一件现代书写工具：环境接近纸白，操作使用低饱和雾青，正文接近墨灰。Logo 可以读作声音与文字、两台设备或两片相连的纸，但不强迫用户理解具体图解。

## 视觉系统

| 项目 | V2 深化规则 |
| --- | --- |
| 环境 | 纸白 `#F2F0EA`，使用轻微明暗层次，不铺明显纹理 |
| 主操作 | 雾青 `#547E86`；白字按钮需保持清楚对比 |
| 反馈 | 浅青 `#A9CDD0`；只用于录音、完成和焦点外环 |
| 正文 | 墨灰 `#243037`；阅读区不让透明材质穿过文字 |
| 深色 | 夜墨 `#202729`；阅读层提升到不透明深灰 |
| 字体 | 控件使用系统无衬线；标题与识别结果使用本地宋体回退 |
| 间距 | 4 pt 基准；主窗口 24 pt 内边距；容器 18 pt 圆角 |
| 宽度 | 主内容最大 920 pt，结果阅读宽度最大 680 pt，避免全屏横铺 |

## 主窗口

- 快捷键、录音操作仍为同一组；结果、原文、复制和再次写入仍为同一组。
- 识别结果使用稳定纸白底和墨灰文字，左侧仅保留一条浅雾青书写线。
- Logo 不在日常窗口反复出现，避免品牌装饰压过内容。
- 错误与恢复沿用原有真实语义：文字保留、可重试或复制，不自动重复写入。

## HUD

- 保持约 288 × 56 pt、状态 13 pt、辅助文字 11 pt；不靠缩小文字换取轻盈。
- 外围可以半透明，中央阅读区保持稳定；浅色、雾青和深色桌面均需可读。
- 声量只改变短线节奏与底部细线；识别使用低频呼吸；完成边线只亮一次。
- “已发出粘贴”不表达为目标端已收到。失败状态持续停留，提供重试和复制。
- 减少动态时取消呼吸与完成动画；减少透明度时改用实色背景。

## 品牌尺寸

评审页提供 128、64、32、16 px 缩放检查。32 px 仍应看到一大一小的关系；16 px 仅用于识别风险观察，不作为菜单栏图标方案。菜单栏应另做单色模板矢量图，不直接缩放彩色位图。

## 文件与验证

- `index.html`：单文件离线评审页，内嵌 V2 Logo、样式与交互。
- `build-preview.py`：从已验证的温润 v1 交互壳生成 V2 页面，不改源页面。
- `warm-v2.css`：V2 纸白、雾青、墨灰主题与响应式/辅助功能规则。
- `verify-preview.cjs`：校验基线资产哈希、离线性、关键设计内容，并复用既有交互模拟检查。
- `baseline-receipt.json`：记录本轮锁定的 Logo 和只读参考页指纹。

```sh
python3 docs/design-warm-writing-v2/build-preview.py
node docs/design-warm-writing-v2/verify-preview.cjs
```

上述校验确认结构、交互模拟、资源和设计约束，不等同于原生 App、真实全局快捷键或跨桌面 HUD 验收。浏览器视觉通过后，下一门槛是用户确认整体气质、主窗口与 HUD，再进入 SwiftUI 应用和正式矢量资产制作。
