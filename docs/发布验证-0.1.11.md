## 实测

硬件：Apple M5 / 16 GB；随已安装 App 提供的 Python 3.12 / MLX；模型来自已校验本地目录。固定公开测试句，不读取口述历史。

命令：`/Applications/VoxInk.app/Contents/Resources/PolishRuntime/bin/python3.12 -B -E -s benchmark/polish_latency.py '<已安装模型目录>' --rounds 3`。

- 均衡模型完整加载约 3.41 秒，固定规则 436 tokens 预热约 1.49 秒。预热移到 resident worker 就绪之前，复用录音阶段已有的后台预热入口。
- 三条中文短句各三次，交替前后顺序：原逻辑中位数 2.1005 秒，新逻辑 0.6711 秒，减少约 68%。九组文字、接受状态及校验原因一致。
- 英语和日语各三次，六组文字及接受状态一致。首次切换语言需要重新计算规则，其后的请求复用。
- 轻量模型三条中文各一次：中位数 0.7129 秒 → 0.3035 秒，文字及接受状态一致。
- 轻量模型英文一次发生格式差异：原模型返回 `source` 字段导致原文回退，缓存后返回正确 `text` 字段；最终文字一致。额外两次复查确认 prompt token 完全一致且复现该格式差异。该结果不能称为逐项一致；模型分段预填充的数值路径不同，不保证生成逐字节相同。
- 基准脚本分别报告最终文字差异、校验决策变化和接受率回退，最终文字差异或接受率回退退出失败。现有保护规则不放宽。
- 本机写入路径取消原有固定 150 ms 计时器，保留一次可取消让出和 1.2 秒后台剪贴板保留。远程原有同步及后台保留时间不变。
