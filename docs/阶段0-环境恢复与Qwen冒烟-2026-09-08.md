## 故障、实验与修复

| 问题 | 最小实验 | 结论与修复 |
| --- | --- | --- |
| 默认命令找不到 Xcode | `mdfind` 查应用，命令级设置 `DEVELOPER_DIR` | 实际安装名是 Xcode-beta.app；保留系统默认目录，使用明确路径 |
| Metal 路径存在但编译失败 | `xcrun metal --version` | 提示缺 Metal Toolchain；官方组件下载完成后编译器可执行 |
| Hugging Face TLS 失败 | 对比直连和已有系统代理访问 | 直连 curl exit 35；通过 127.0.0.1:1082 返回 HTTP 200，沿用既有代理下载 |
| stdout 混入诊断 | 首次真实转录输出 10 行，仅 1 行 JSON | 新增 JSONOutput 保留原 stdout，依赖诊断转 stderr；复跑恰好 1 行 JSON |
