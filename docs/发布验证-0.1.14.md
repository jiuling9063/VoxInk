# 0.1.14（16）发布验证

日期：2026-10-14。发行方式：Developer ID 签名、Apple 公证的 macOS arm64 DMG，经 GitHub 正式 Release 分发。最低系统 macOS 15。

## 改动范围

- UU 前台的 Option+Space 系统事件不再因远程监听处于启用状态而被丢弃；两个事件来源共用按键去重。
- 首次引导和快捷键设置页共用 UU 设置说明，随当前语落快捷键更新。
- 引导增加阶段导航、编号准备项、常驻底部操作、未完成原因与测试配置摘要。
- 更换快捷键或录音操作方式后清除旧输入验证；注册失败或保留原快捷键不会清除证据。
- 剪贴板同步引导支持默认同步的工具；不声称自动读取或设置第三方选项。
- 保留稍后设置、进度恢复、旧用户免打扰及真实文字、语音确认机制。

## 已确认的实机证据

- 用户在本机运行含本次快捷键修复的临时包，向 UU 中的远端 Mac 输入，确认 Option+Space 连续 3 次都能录音并写入。
- 实测时 UU 配置了当前 Option+Space 为“仅控制端响应”。该证据针对本次远程会话，不代表所有客户端、全屏或干净系统均已通过。

- App 公证 `f9f28629-b5ec-4b61-aec5-893c46f755c8`：Accepted；票据附加与验证通过。

## 边界

- 未改动识别模型、润色算法或粘贴核心逻辑；第三方设置仍由用户完成和确认。
- 旧版记录的远端额外语音浮窗未在所有环境复核，不能将本次 Option+Space 修复视为解决所有快捷键冲突。
