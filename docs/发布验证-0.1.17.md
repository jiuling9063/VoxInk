# 0.1.17（19）发布验证

日期：2026-10-21。目标：Developer ID 签名及 Apple 公证的 macOS arm64 DMG，支持 macOS 15+。

## 改动范围

- 本地与云端提供「原样整理 / 自然润色」，选择持久化，处理中禁止切换。未设置过的用户使用原样整理，已有选择保持不变。
- 提示词与保护规则按模式配套；保护数字、路径、代码、引用、否定、不确定性、识别到的名称及部分动作顺序。不合格输出回退原文；启发式检查不能证明语义完全一致。
- 新建硅基流动连接默认使用 Qwen/Qwen3-ASR-1.7B 和 Qwen/Qwen3.5-122B-A10B，润色关闭思考、temperature=0.2。已有连接与钥匙串数据不迁移、不覆盖。
- 四种翻译、安装/API 说明与自动测试同步更新。
- 独立发布 worktree 不包含主工作区的遥控器实验。local-tests、录音、个人设置与原始测试报告不提交。

## 验证

- Debug Swift 自动测试通过；Python 87 项通过；英语、日语、韩语、繁体中文各覆盖 609 条源码文案，664 条翻译和占位符校验通过。
- 前一轮真实接口对照：5 个硅基流动润色模型、6 条固定样本、两轮共 60 次请求。千问 3.5-122B 本轮 12 次成功，耗时中位数 0.73 秒，保护检查 12 次接受。样本规模有限，不视为全面准确率基准。
- 前一轮 Qwen ASR 9 次固定音频接口测试成功，中位约 0.71 秒；真实应用音频预处理管线额外两次验证成功。曾出现一次未确认原因的文件导入异常，后续固定文件复测成功；未将其声明为已定位修复。
- 本版不重新声称 UU 远端完整录音到落字已验收。

- Release 串行测试启用本机 HTTP fixture：345 项通过，5 项显式启用的集成测试跳过；真实 URLSession JSON、multipart 和重定向拒绝已覆盖。
- 正式 App 打包后的 Python / Metal 自检通过，42 个原生运行时文件已签名；额外启用本地模型双模式集成测试，1 项通过。当前样本两种模式均保留原句，此项证明运行兼容性，不代表润色质量提升。
- 主程序、本地识别 Worker 和 Python 润色运行时均按现有依赖锁重新构建或打包，签名通过深度严格验证。Bundle ID 与 Developer ID designated requirement 和旧版相同。
