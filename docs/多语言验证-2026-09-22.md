## 本地模型实测

使用锁定的本地 Qwen 识别模型与系统合成语音，不含用户录音。每种语言分别运行手动指定与自动检测；两种模式得到相同的样句输出。以下是代表性结果，不是准确率评测。

| 语言 | 样句 / 观察 |
| --- | --- |
| 普通话 | 「今天下午三点开会，请带上项目资料。」与样句一致 |
| 粤语 | 「聽日下午三點開會，記得帶埋份文件。」输出简体粤语；后处理可选择繁体 |
| 英语 | “Please open the project folder. We have a meeting at three tomorrow.” 与样句一致 |
| 日语 | 「明日の午後三時に会議があります。資料を持ってきてください。」中「会議」误识别为「開議」 |
| 韩语 | 「내일 오후 세 시에 회의가 있습니다. 자료를 가져오세요.」与样句一致 |

润色使用已安装的均衡模型、新版 worker 和禁止网络访问的运行方式：

- 英文、日文、粤语各一条：接受结果，原语言及内容保持不变。
- 韩语一条：生成结果涉及内容改动，被校验拒绝，返回原文。
- 四次生成耗时约 0.66–0.90 秒，不含加载，不代表长文本或其他设备性能。
- 当前外语策略倾向保留原文，不能据此宣称已达到成熟的外语语法润色效果。
