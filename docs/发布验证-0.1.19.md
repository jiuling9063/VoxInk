# 0.1.19（21）发布验证

日期：2026-10-26。目标：Developer ID 签名及 Apple 公证的 macOS arm64 DMG，支持 macOS 15+。

## 范围

统一文字式选择控件，模型 ID 可直接编辑；保留青绿色强调色。应用于所有包含相关控件的界面，详见 [UI 设计复核](UI设计-0.1.19.md)。沿用现有服务、钥匙串、数据保留和输入流程。

## 验证

- 四种翻译各覆盖 607 条源文案、672 条翻译资源，占位符检查通过。
- Release 串行 Swift 测试启用本机 HTTP fixture：348 项通过、5 项需显式条件的集成测试跳过。
- 新增模型 ID 更新测试，覆盖转写/润色持久化、原连接与钥匙串内容保留、空值和换行拒绝、缺失连接及忙碌状态。
- 原生交互检查及边界见 UI 设计复核；不声称重新完成 UU 真人端到端验收。
- 正式 App 内置 Python / Metal 自检通过，42 个原生运行时文件签名；主程序与本地识别 Worker 按既有锁定依赖构建。
