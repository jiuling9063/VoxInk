# 离线润色组件安装（开发验收）

此流程用于验证已安装模型与 Python 可以搬迁到新目录。不是经过公证的正式分发包；目前仅在当前 Apple Silicon Mac 上验收。开发者身份审批期间可以继续完成安装逻辑，正式分发前仍需兼容性验证、第三方许可清单及签名公证。

## 导出

使用 Python 3.11 或以上，在仓库根目录运行：

```sh
python3 script/export_polish_bundle.py --output output/polish-offline-preview
```

导出读取当前用户 Application Support/VoxInk/Polish/runtime.json，要求解释器已独立迁移。输出目录必须不存在。组件包含完整解释器、模型、运行脚本、文件清单和安装入口，不包含用户转录、词典或系统授权。

## 安装

包内的 `安装润色组件.command` 使用随包 Python，因此目标不需要预装 Python、uv 或联网下载。双击运行，或在终端执行：

```sh
bash /path/to/polish-offline-preview/安装润色组件.command
```

默认安装到当前用户的 Application Support/VoxInk/Polish。每次安装使用独立版本目录；检查架构、清单与哈希后复制，真实禁网推理成功才原子替换 runtime.json。失败保留原配置并清理本次新目录，旧安装不自动删除。安装锁防止同目录同时安装。

验证时可用 `--destination /absolute/test/directory` 指向隔离目录，避免更改日常 App 的润色配置。运行端支持 arm64 macOS，但最低 macOS 版本和其他机器尚未验收。哈希用于检测损坏，不等于发行者身份认证，只运行可信来源的包，不绕过系统安全警告。
