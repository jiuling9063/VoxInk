# 温润书写 · 独立对比稿

轻盈科技 v4 已获用户确认，作为视觉定稿基准；本轮独立探索温润书写，供用户对照，原生 App 不改动。

## 最新反馈与取舍

用户不喜欢用笔墨描绘原 V 形 Logo。首次生成的笔墨版本 `assets/logo-warm-v1.png` 标记为弃用，不进入演示页。

改用全新柔和几何形式：一段连续浅杏色弧面，形成回环与页面般的展开，配合暖白底板。使用 `assets/logo-warm-geometric-v2.png`，是温润方案候选，尚未确认。已通过的冰青玻璃 Logo 不变。

## 视觉语言

温润体现为接近纸白的环境、适度的暖色、安静的界面边界和亲近的几何造型。主窗口沿用 v3/v4 的秩序：标题栏设置、同一行的快捷键与录音、结果与后续操作成组。阅读区加入本地宋体字体回退，按钮、设置与 HUD 坚持无衬线字体保证识别。

| 参数 | 温润方案 |
| --- | --- |
| 环境 | `#F1EDE5` |
| 主操作 | `#875036` |
| 光效 | `#D7AD6B` |
| 正文 | `#302B26` |
| 深色背景 | `#25221E` |
| HUD | 与定稿基准一致，约 288 × 56，状态 13 / 11 px，背景透明度 58% |
| 完成光效 | 700 ms 四周柔光一次，使用暖琥珀色；减少动态时静态亮边 |

提供暖白、薄瓷、灯下三个材质细化预览，保留深色与减少动态控件。背景选择的内部 `blue` 值沿用原演示接口，温润页显示为“暖色”，不影响业务逻辑。

## 公平比较

页面、状态、交互时序、HUD 尺寸及可读字号与科技版相同。主差异集中在材质、配色、Logo 及阅读区字体。页面顶部可以另开已定稿版，品牌区并排展示两种 Logo，页尾列出对照表。

`approved-baseline.json` 记录本轮开始时科技版页面、Logo、样式及构建脚本的 SHA-256。验收时复核，确保对照稿没有改写定稿基准。该收据仅确认已通过视觉的文件版本，不代表原生实现或生产资产已完成。

## 文件与验证

- `index.html`：单文件离线对比页，图像与样式内嵌。
- `warm.css` / `build-preview.py`：温润样式与构建脚本。
- `assets/logo-warm-geometric-v2.png` / `prompts.md`：内置 imagegen 原始图及生成记录。
- `verify-preview.cjs`：相同功能流程、参数、减少动态的模拟 DOM 检查。
- `approved-baseline.json`：科技版视觉基准指纹。

```sh
python3 docs/design-warm-writing-v1/build-preview.py
node docs/design-warm-writing-v1/verify-preview.cjs
```

之前浏览器工具阻止自动访问本地文件，本轮不绕过限制。可检查脚本、结构和资源完整性，实际字体呈现、玻璃合成及交互观感仍待打开页面查看。位图 Logo 尚需小尺寸验证和正式资产制作。

本轮检查通过：离线页面生成、原有交互逻辑、HTML 嵌套、当前几何 Logo 内嵌、弃用笔墨稿排除，以及全部科技版基准文件的 SHA-256 复核。真实浏览器视觉仍待评审。
