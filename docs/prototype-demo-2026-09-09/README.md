# VoxInk 本地原型演示

打开 [index.html](index.html) 查看 22 张已核对的原生组件画面。包含主窗口 12 种受控状态、深浅色就绪、长结果原文对照，以及三个设置页、词条编辑和两种快捷键模式。点击画面名称、前后按钮或使用左右方向键浏览。

图片来自检查程序对自身原生组件的 `NSView.cacheDisplay` 导出，不是桌面截屏；不包含系统窗口边框、设置工具栏和合成效果。实际交互布局已另用 CUA 查看。设置页和编辑弹窗具有透明背景，演示页面按导出外观补上深浅色背景；下载的原始 PNG 保留透明度。检查工具标注模拟数据，音频、识别、写入和保留录音使用内存替身。它不能替代真实输入或正式性能验收。

## 重新导出

从项目根目录执行：

```bash
./script/run_interface_check.sh --demo-output "$PWD/docs/prototype-demo-2026-09-09/assets"
```

切换需要的场景，按 ⌘⇧E 或点击“导出演示图”。每次产生一组随机文件名的 PNG 和 JSON，不覆盖已有图片。核对图片后，在 `captures.json` 添加文件名、标题和说明，再运行：

```bash
python3 script/build_prototype_demo.py --directory docs/prototype-demo-2026-09-09
```

生成器检查 PNG 文件头、尺寸、模拟标识与对应元数据，生成本地页面及包含 SHA-256 的 `manifest.json`。页面没有远程资源依赖。目录内只应保存模拟数据；真实录音及转录不放入演示包。

## 当前验证与限制

- 22 张 PNG 已查看核对；主窗口图片为 1320×1550 像素，包含 660×600 点产品组件和开发工具控制栏。长结果仅导出当前可见区域；原文另有展开并滚到底部的画面。
- 正式 AppDelegate 的窗口下限为 660×600 点；ContentView 的 620×520 点下限属于内部组件约束，前轮使用它进行更小尺寸检查。
- 导出快捷键和 PNG/JSON 写入通过；生成器、HTML 本地链接、PNG 哈希、JavaScript 及启动脚本语法检查通过。
- 解锁后先复核键盘导航，导出仍为 `full_keyboard_access=false`；Control-F7 未改变该值，系统设置点击两次返回 `noWindowsAvailable`。后续设置页导出仍为 false，系统截图开关也为关闭，没有留下导航设置变更。Apple 的 [键盘快捷键说明](https://support.apple.com/en-us/102650) 说明 Control-F7 / Fn-Control-F7 用于切换 Tab 遍历范围。
- 本轮确认词条编辑 Tab/Shift-Tab、Return 保存、Cmd+, 打开设置及模式菜单方向键/Return。模拟词条“雨落 → 语落”仅保存在检查程序内存；两种操作方式检查后已恢复按住说话。
- 内置浏览器明确拒绝 `file://` 页面，并禁止绕过 URL 安全策略；没有另起服务器或改用其他浏览器绕过。随后用户自行查看，并明确确认“没问题，可以切换”。页面显示与画面切换按用户实测通过；自动浏览器检查仍受策略限制，未将人工确认记为自动化结果。
- 全窗口键盘、菜单完整遍历、VoiceOver、当前产品实体输入与完整正式门槛仍待验证；本批交付是组件状态演示，不代表全部原型目标完成。
