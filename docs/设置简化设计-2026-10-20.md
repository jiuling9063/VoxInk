# 语音与润色设置简化

本次是工作目录中的开发版界面改进，尚未作为新版 GitHub 安装包发布。

## 用户任务

用户要完成的是「语音变文字 → 可选润色」，只需要决定每一步在哪里处理。服务连接是完成任务的手段，不应要求用户先理解连接管理、创建用途、再手动激活。

## 参考的官方流程

- [MacWhisper：设置 AI 服务](https://docs.macwhisper.com/article/58-setting-up-ai-providers-in-macwhisper)：直接选择服务商；在线服务通常填写密钥和模型，自定义服务才需要地址；首次添加后自动选用。
- [VoiceInk：云端服务商](https://tryvoiceink.com/docs/cloud-providers)：选择服务商、输入密钥并验证；密钥放在钥匙串，服务页面提供获取密钥入口。
- [Superwhisper：模型](https://superwhisper.com/models)：语音识别与后续语言处理是两项独立选择，可分别采用本地或云端。

借鉴以上交互，不复制它们的订阅、代理服务或完整模式系统。语落使用用户自有密钥，保持两项功能独立配置。

## 调整

| 原流程 | 新流程 |
| --- | --- |
| 转录引擎、润色模型分别占一个侧栏入口 | 合并为「语音与润色」，两块设置同屏显示 |
| 处理服务、添加服务商、管理连接三个入口 | 一个处理方式菜单：本地、已有服务和新服务商 |
| 添加后再选择连接，润色还要打开开关 | 保存并使用；润色菜单直接选择不润色、本地或云端 |
| 首屏展示用途、名称、模型 ID、地址、密钥 | 用途由所在区域决定，预设填好名称/地址/模型，通常只填密钥 |
| 同一家服务用于转写和润色需要重复填密钥 | 可复用另一项功能保存的同服务商密钥 |
| 测试入口藏在管理连接里 | 当前服务旁直接设置、测试；结果就近显示 |
| 偏好设置多处重复放置模型选项 | 统一到「语音与润色」分类，系统权限独立保留 |

高级设置仍允许更改模型、地址、超时、额外参数和删除连接。没有预设模型的服务必须填写模型；自定义接口直接展示地址，避免把必填项藏起来。

## 保留规则

- 启动或打开设置不改变原有服务、模型、密钥或开关。
- 取消新配置、钥匙串写入失败、密钥复用失败，均保留原选择。
- 不自动测试、不发新增网络请求；保存后实际录音/润色才按选定服务处理。
- 密钥复用仅限同一家内置服务商的准确端点；不跨服务商、不复用到自定义或相似域名。
- 同服务商多条现有配置继续保留，复用密钥优先使用另一项功能当前选中的账户。
- 不润色只关闭处理，保留配置；删除当前连接需确认，并切换回本地。
- 原有本地模型、词典、取消与自动写入安全检查继续使用。
