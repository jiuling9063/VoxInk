### 3.1 Turbo 名称冲突已解析

WhisperKit 0.18.0 按 `*<variant>/*` 搜索仓库目录，因此：

- OpenQuack 原参数 `large-v3-turbo` 无法匹配下划线目录；
- `large-v3_turbo` 会同时匹配标准版和 954MB 版，仍然有歧义；
- 远端设备支持配置把 `openai_whisper-large-v3_turbo_954MB` 列为 M2/M3/M4 支持项；
- 冒烟测试必须传入完整解析参数 `openai_whisper-large-v3_turbo_954MB`。

该目录内 22 个文件共 1,052,848,880 字节，全部大小和 SHA-256 已进入机器可读清单。当前配置尚未列出 M5，因此这里只解除 M4 冒烟阻塞，不能替代目标 M5/16GB 的最终兼容性验证。

## 4. 校验方法

- Hugging Face API `?blobs=true` 提供模型 revision、model card 许可证、文件大小和 LFS SHA-256；
- LFS 大文件没有下载，直接记录固定 revision 下的官方 LFS SHA-256；
- 非 LFS 文件使用包含固定 revision 的下载 URL 读取内容，读取字节数必须与 API 声明一致，再计算 SHA-256；
- WhisperKit 目录文件数、逐项大小之和与 `reported_size_bytes` 交叉校验；
- `speech-swift` 固定 revision 的 `LICENSE` 内容确认为 Apache License 2.0。

## 5. 网络状态记录

AutoGLM 本地 token 服务仍返回 HTTP 503，未作为证据来源。网络恢复后，Hugging Face 官方 API 与固定 revision 内容下载成功；GitHub raw 内容和部分 `git ls-remote` 成功，但 GitHub API 仍间歇出现 SSL 超时或 HTTP2 framing 错误。清单只记录实际读取成功的证据，不把失败响应推断为成功。
