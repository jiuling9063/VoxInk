# Mac App Store 测试清单与本轮结果

基线：已安装直装版 0.1.10（12），本轮修改的是独立验证程序和测试工具。主机为 Apple M5 / macOS 27 beta，不能将本机结果等同于稳定系统或商店审核通过。

测试目标来自本项目的录音、模型下载、离线推理和跨应用输入场景。[Apple 审核指南](https://developer.apple.com/app-store/review/guidelines/)要求提交前检查崩溃和缺陷，并保证元数据完整准确；下表是项目自己的验收标准，不是 Apple 保证通过的清单。

## 本轮完成

| 下载服务异常 | 17 项契约检查 + 13 个传输/生命周期场景通过 | HTTP 404/503、离线、超时、截断、超量、篡改、取消、重试、只读目标、重复请求、失效连接；网络异常由 URLProtocol 注入 |

| 安装包静态检查 | 签名完整、44 个原生文件依赖与最低系统版本一致 | 无开发机非系统绝对依赖；二进制最低版本未高于声明的 macOS 15.0；不代表已在 macOS 15 实机运行 |

Swift 输出为 UI 目标 163 个测试（含 1 个默认跳过项）、Core 目标 116 个测试。随后单独启用首次安装项并完成隔离缓存复测。因此最终覆盖 279 个不同的 Swift 测试，不把重点复跑及首次安装两次尝试重复相加。

首次尝试在仓库默认构建目录遇到资源包的 Finder 扩展属性导致签名失败，测试没有运行。改用 `/tmp/voxink-app-xcode-beta` 后完整执行成功，没有改动正式 App 或关闭系统安全保护。

首次安装测试第一轮用了新模型目录，但未隔离共享 Hub 缓存，因此不能作为严格的冷缓存证据。第二轮通过 `test_bundled_first_install.sh` 使用全新的 Hub、Xet 和资源缓存，禁止隐式令牌、禁用库遥测，才计入上表。此测试仍在当前用户和系统下运行，不是新电脑、干净 macOS 用户、完整商店版或全档模型验收。

## 修正的问题

独立 XPC 下载服务原来没有保存下载任务，客户端失效后无法主动取消它。新增连接级任务管理，在失效/中断时取消下载，校验后写入前再次检查取消状态；拒绝同一连接的并发请求。13 个新增场景覆盖传输取消与任务失效竞态，但未声称完成真实慢速网络中途断开 XPC 的端到端验证。

| P1 干净安装与权限 | 支持范围内的稳定 macOS、新用户或另一台 Mac：首次启动、允许/拒绝麦克风、撤回后恢复、无模型离线启动、卸载重装 | 无环境配置要求；未授权时明确说明且可恢复；不删除其他用户文件。当前测试机不能覆盖此项 |

| P1 存储边界 | 沙盒容器重启访问、老用户模型/词典授权迁移、失效书签、只读路径、磁盘写满、升级中断 | 数据保留、错误可恢复；现有临时目录和只读句柄检查不覆盖磁盘写满或跨版本真实迁移 |
| P1 录音设备与恢复 | 内置/USB/蓝牙麦克风、设备切换/拔出、睡眠唤醒、静音/噪声、60 秒上限、取消、崩溃后音频恢复及过期清理 | 无卡死或幽灵录音，临时音频按约定清理；本轮自动化只验证相关逻辑，不录制用户声音 |

| P1 隐私与隔离 | 实际商店版录音/识别/润色期间网络观察；日志、崩溃报告、恢复文件、剪贴板恢复及词典导入路径 | 不上传用户语音或正文；无多余权限；与隐私政策一致。单次 socket 拒绝和静态检查不是全面隐私审计 |
| P1 语言与界面 | 五种界面语言逐页窄窗口/滚动/弹窗、键盘导航、VoiceOver、减少动态效果；真人多语种语音，重点日语同音词 | 无截断、混语或不可操作控件；明确识别质量边界；译文完整性检查不能替代母语和真人语料验收 |

TestFlight 可用于将实际上传的构建交给测试者验证安装与使用体验，参见 [Apple TestFlight 流程](https://developer.apple.com/help/app-store-connect/test-a-beta-version/testflight-overview/)。本轮没有提交审核，也没有发送 Apple 技术咨询。

## 可复现命令

```sh
VOXINK_UI_LANGUAGE=zh-Hans DEVELOPER_DIR=/Applications/Xcode-beta.app/Contents/Developer \
  swift test --package-path app --scratch-path /tmp/voxink-app-xcode-beta
python3 -m unittest discover -s script/tests
python3 script/check_localizations.py
bash script/test_app_store_probe.sh

# 明确联网：在新临时目录下载轻量模型，使用 App 内置组件。
bash script/test_bundled_first_install.sh

# 只读检查；当前直装版预计返回 1，JSON 中列出商店阻塞项。
DEVELOPER_DIR=/Applications/Xcode-beta.app/Contents/Developer \
  python3 script/check_app_store_bundle.py /Applications/VoxInk.app
```
