## 实现

词典保存“识别词 → 正确写法”，保存前使用已有基础规则规范化。最多 100 条，每个字段最多 64 个字符及 512 UTF-8 字节，总计最多 4096 个字符及 16384 字节。相同来源词、重复 ID、空字段及不受支持的结构拒绝保存。

校正在 OpenCC 后、标点规则前执行：按系统词边界匹配、英文区分大小写、较长词优先、替换结果不再连锁替换。URL、邮箱、路径、标记代码等原文片段保持保护。普通英文名称可以被明确配置；代码上下文中的标识符继续保护。包含数字的名称只能保持原有数字写法，例如 `Qwin3 → Qwen3` 可以，`Qwin3 → Qwen4` 拒绝。没有增加中文数字转换或猜测数值。

词典位于 `~/Library/Application Support/VoxInk/Dictionary/words.json`，使用带版本的 JSON。写入私有临时文件、同步后原子替换；损坏或不兼容文件保留，并提示重新读取。只有保存成功才发布新规则，保存失败保持此前有效配置。退出等待进行中的保存完成。

每次识别开始时固定一份规则快照；编辑影响下一次识别，不改变正在处理的会话。原始识别文字保持只读。词典加载失败不阻止基础识别，但提示本次未应用词典。预览文字只在设置会话中使用，不保存、不录音、不粘贴。

## 调试与 GUI 证据

初始边界实现使用 NLTokenizer，本机 macOS 27 Beta 对 `雨落 `、`雨落 123` 的诊断出现遗漏“落”的分词结果。改用 Foundation `enumerateSubstrings(.byWords, .localized)`，并排除空白分词，固定测试覆盖：

`请打开雨落。下雨落地后再说。` → `请打开语落。下雨落地后再说。`

实际 GUI 添加 `雨落 → 語落` 后保存为简体 `语落`；预览中只纠正完整名称，保留“下雨落地”、URL、反引号内文字及 `123.45`。随后编辑为 `VoxInk`；尝试增加数字 `VoxInk4` 时显示错误并禁用保存，取消该修改。

退出后核对单条文件已保存编辑结果；最终构建重启恢复同一词条，预览输入恢复初始句子，证明旧预览未写入磁盘。最终编辑表单的“识别词”“正确写法”标签均可见；取消编辑并删除测试词条后，UI 为 0/100，文件 entries 为空。

新增/编辑/保护预览检查发生在最终退出等待与字段标签调整之前；最终 152 项测试覆盖退出等待逻辑，最终 GUI 复核重启恢复、字段标签与删除。未将这些局部检查外推为所有外观及键盘状态通过。
