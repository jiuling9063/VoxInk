# ASR 热词提示对照

日期：2026-09-09。结论：当前固定 Qwen 候选的词表上下文未通过无语音负样例门槛，不接入产品常驻识别。识别后用户词典校正保持可用。另确认现有产品存在低音量噪声误识别，必须优先补齐语音活动检测。

## 实现与限制

[Qwen 官方推理接口](https://github.com/QwenLM/Qwen3-ASR/blob/main/qwen_asr/inference/qwen3_asr.py)提供可选 context。本机固定的 speech-swift revision `d603472b11c21f5fb6492e9448a04ee669d0bf64` 同样提供该参数，并把它编码到系统上下文。这仅证明存在接口，不能证明词表偏置安全有效。

新增基准入口按请求读取 `hotwords`：最多 32 条、总计 1024 UTF-8 字节；单条最多 64 字符及 512 字节，只允许名称、数字、空格及有限名称符号。拒绝换行、模板特殊标记和不合规输入。去重保持顺序，使用逗号分隔，不添加转录指令。

提示预算由固定模型同一套 `vocab.json`、`merges.txt`、`tokenizer_config.json` 和上游 Qwen3Tokenizer 实际编码计算，最多 256 token，超限按完整词条停止。分词器只在实验请求有词条时加载，空词表保持 nil 上下文。结果新增 `context_tokens`、`hotword_count` 和实验输出策略标签，原响应字段保持兼容。

最终版本必须显式传入 `--experimental-hotwords`，仅允许批量基准模式；与 resident、prepare-only、简体指令提示不兼容。产品常驻模式拒绝该开关。App 的请求协议和词典处理链本轮没有接入词表上下文，产品包没有重新构建。

## 最终对照

同一禁网 Release 模型进程执行 15 个请求：三段既有音频，以及 3 秒数字静音、3 秒固定随机种子低音量噪声，分别使用空词表、2 条无关专有词、32 条预算词表。词表与音频均未上传。三段真实音频没有人工冻结参考文本，因此不计算 CER 或准确率。

| 样例 | 空词表 | 2 条词表 | 32 条输入词表 |
| --- | --- | --- | --- |
| SMOKE-001 | 基线 | 原始文字完全一致 | 原始文字完全一致 |
| SMOKE-002 | 基线 | 原始文字完全一致 | 多出一个句号 |
| SMOKE-003 | 基线 | 原始文字完全一致 | 原始文字完全一致 |
| 数字静音 | 空结果 | 回显词表，15 字符 | 回显词表，329 字符 |
| 合成低音量噪声 | `嗯。`，2 字符 | 回显词表，15 字符 | 回显词表并重复，495 字符 |

两条词表实际为 13 token；32 条输入在预算下选取 26 条、247 token。数字静音和噪声的上下文回显包括本轮人工构造的“紫藤星云研究所”“榛果电报码”，属于无音频依据的新增内容。

第一轮探索同样为 15 请求，采用另一组确定性合成噪声：其空词表输出为空，加入词表后仍回显。最终脚本固定为 `Random(20260909)`；不把不同噪声波形之间的差异描述为同一文件不稳定。两个轮次都未通过负样例门槛。

15 请求完成不等同于 15 项质量测试通过。最终回执明确 `negative_no_text_gate_passed: false`。耗时仅为开发观察，含冷/热差异，不作为端到端延迟或正式性能门槛。

## 产品入口复现与清理

保持前轮 App 包不变，从原生“导入音频”选择最终脚本生成的 `low-noise.wav`。产品也显示“识别完成”，结果为 `嗯。`，并生成一条未完成录音。该结果证明噪声穿过了当前产品的音频检查；不是只在裸模型调用中发生。

本轮仅导入展示，没有自动粘贴或发送消息。通过界面删除临时保留录音，并退出以清除临时文字，随后恢复原 App。原始桌面音频及模型没有改动。产品数字全零过滤已有测试，但它不能替代环境噪声/语音活动检测。

## 复现命令

先退出 VoxInk，避免并存两份模型。输出目录必须尚不存在：

```bash
DEVELOPER_DIR=/Applications/Xcode-beta.app/Contents/Developer swift test --package-path benchmark/qwen-smoke --scratch-path /tmp/voxink-qwen-xcode-beta
DEVELOPER_DIR=/Applications/Xcode-beta.app/Contents/Developer swift build --package-path benchmark/qwen-smoke --scratch-path /tmp/voxink-qwen-xcode-beta -c release --product voxink-qwen-smoke --disable-automatic-resolution
python3 script/check_hotword_context.py \
  --worker /tmp/voxink-qwen-xcode-beta/out/Products/Release/voxink-qwen-smoke \
  --cache-root '/Users/jiuling/Library/Application Support/VoxInk/Models/bc441bd1e4295c1f42d9879f056049a925b6e013' \
  --output benchmark/results/hotword-context-recheck
```

脚本退出 0 只表示实验完成并通过结构/预算检查；必须读取 `negative_no_text_gate_passed` 判断负样例门槛。本轮该值为 false。
