# 完整原型验收清单

更新：2026-09-09。依据根目录《开发需求文档》v0.5、《技术架构方案》v1 和当前实测记录。

## 交付定义

交付可实际运行的原生 macOS App 原型，覆盖首次准备、日常输入、偏好设置与异常恢复。界面必须反映真实能力，不以静态稿、模拟进度或单次测试替代实现和验收。正式默认模型、性能与稳定性门槛没有通过前，保留开发预览标识。

视觉采用原生系统字体、蓝色重点操作、系统自适应背景和清晰状态文字。保留可靠的 AppKit 主窗口生命周期，SwiftUI 承载内容；主窗口、菜单栏和设置共用一个 AppStore。日常主界面仅保留快捷键说明、录音/导入、当前结果和恢复操作；诊断工具折叠，偏好设置独立。

## 执行顺序

1. 完成真实状态驱动的主界面、引导、设置和错误恢复，并运行自动测试和 GUI 检查。
2. 补齐快捷键备选、开机启动、模型安装/修复、音频失败重试和文本规则；每批做行为回归。
3. 检查全状态视觉、键盘操作、窗口恢复、深浅色和多屏反馈，形成原生原型演示。
4. 在可控的可清空测试框完成自动化能够覆盖的矩阵；实体快捷键、远程应用和参考文本需要用户参与的部分集中交付明确步骤。
5. 如实记录未满足的正式门槛；门槛通过后再进入润色与分发。整个目标在所需工作未完成时保持进行中。
