# 0.1.20（22）发布验证

日期：2026-11-01。目标：Developer ID 签名、Apple 公证的 macOS arm64 DMG，支持 macOS 15+。

## 范围

新增硅基流动“获取模型”，官方接口分别以 `sub_type=speech-to-text` 与 `sub_type=chat` 获取转写和润色列表。设置页及连接编辑页提供搜索与明确选择，保留手动 ID 输入；其他服务商保持手动输入。获取、失败、取消不改写模型或密钥。切换模型清除旧模型的默认专属参数，保留用户自设参数。

功能实现提交：`6f697f8`。接口依据：[硅基流动 List Models](https://api-docs.siliconflow.cn/docs/api/models-get)。

- 四种翻译各覆盖 614 条源文案、679 条翻译资源，占位符检查通过。
- 新增 12 项模型目录测试，覆盖官方用途筛选、去重、非法 ID、认证与 HTTP 错误、取消、空列表、未保存/复用密钥、地址隔离、配置不变及默认参数清理。
- 原生模拟界面检查：设置页与编辑页获取、搜索、选择、取消；浅色、深色与最小窗口布局通过。未重新声明所有模型推理质量或 UU 真人端到端输入验收。
