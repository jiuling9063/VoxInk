# 语落 VoxInk 0.1.4 邀请试用版

App 0.1.4，构建 6。适用于 Apple Silicon Mac、macOS 15 或更高版本。App 已完成 Developer ID 签名与 Apple 公证。

## 本次更新

- 一体式原生标题工具栏：保留系统窗口按钮，当前页面标题随导航更新；点击本机模型状态可进入转录引擎设置。
- 统一浅色与深色界面、字体、卡片和按钮反馈；合并重复状态，常用录音入口更突出。
- 优化首次引导、文字与词典、历史、统计和偏好设置；远程输入配置可展开，移除持续呼吸动画。
- 整合此前本机试用的自动润色、模型自适应选择、常驻进程复用、口头词整理和 UU 远程粘贴改进。

## 安装或升级

退出旧版，打开 DMG，将 VoxInk 拖入「应用程序」并替换旧版，再从「应用程序」启动。已有模型、用户词典和偏好设置继续复用；App 不包含模型权重。

首次使用须允许麦克风；自动写入还需要辅助功能权限。先点选目标输入框，再使用设置中显示的快捷键。窗口内录音与导入仅展示结果。

## 本地润色

「自动润色后写入」对新用户默认关闭，升级保留已有设置。启用后先识别、再润色、最后写入一次；超时或校验失败时使用未润色文字，识别原文保留。自动模式仅选择已安装模型，不自动下载、不调用云端。

响应更快、兼顾速度与效果、效果优先的润色等待上限分别为 6、12、30 秒。全新设备仍需单独准备 Python/MLX 润色运行环境；本版不提供从零自动安装该环境。详细策略见 [0.1.3 说明](试用版说明-0.1.3.md)。

## 验证范围

发布前已通过 241 项 Swift 测试与 60 项 Python 脚本测试。已检查一体式标题栏、模型状态导航、浅深色、660 点窄窗口、词典弹窗和长文本显示。跨设备首次安装、更多机型的润色性能及真实远程输入仍需试用验证。

升级后请检查常用输入框内连续两次快捷键输入、Esc 取消和文字是否仅写入一次。反馈时请使用 [试用反馈模板](试用反馈模板.md)，不要附上包含隐私的录音或输入内容。
