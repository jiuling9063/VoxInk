# 语落 VoxInk 0.1.7 邀请试用版

App 0.1.7，构建 9。适用于 Apple Silicon Mac、macOS 15 或更高版本。

## 本次更新

支持批量导入自定义纠正词库。在「文字与词典 → 词库文件」保存模板，用 Excel 编辑后保存为 UTF-8 CSV，再选择「导入 CSV」。也可导出当前词库备份。

CSV 首行为「识别词,正确写法」，每行一组纠正词。导入前展示新增、重复、冲突和无效项；确认后只加入新增有效词条，不覆盖已有写法。同一文件的冲突保留首次有效写法。重复、冲突、无效项跳过；超出总容量则阻止整个导入。词库变化后旧预览失效，需重新预览。

词库在本机读取与保存，不上传服务器；用于识别后的文字纠正，不训练识别模型。沿用 100 条词条、每项 64 个字符、总计 4096 个字符的限制，导入文件最大 128 KB。数字、网址、路径和代码保护规则不变。

同时包含 0.1.6 的全部改进：页面与标题对齐、侧栏底部版本信息、润色页折叠详情、三步使用引导，以及部分口吃式重复和停顿的整理。

## 安装与使用

退出旧版，将安装盘中的 VoxInk 拖入「应用程序」替换，再启动。已有模型与偏好继续复用，无需重新下载。App 内置润色运行组件，新设备无需配置 Python/MLX。

首次使用允许麦克风并下载转录模型。自动写入需要辅助功能权限；润色模型按需下载，下载完成后在本机运行。

## 验证范围

252 项常规 Swift 测试通过，另有 1 项真实下载测试按默认配置跳过。验证了 CSV 编解码、格式错误、重复冲突、容量限制、过期预览与保存失败保护；实际界面检查了文件选择、导入预览、合并生效与导出内容。

上一版已通过 66 项 Python 测试和实际润色模型对比。本次未改动润色逻辑。更多实体 Mac 与真实词库仍需试用验证。
