# 主窗口状态矩阵验证

日期：2026-09-09。结论：12 种受控状态的深浅色主窗口检查通过；UX2 的实体输入与完整键盘验收仍未完成。

## 检查方式

新增独立 `voxink-interface-check`，复用产品 `ContentView`、`SetupView` 和 `AppStore`。通过公开的加载、录音、结束、导入、取消、复制等操作进入状态；不直接改写界面状态，也不复制一套静态主窗口。

录音、转录、粘贴和录音保留采用内存替身，偏好使用 `nil`，复制不写入系统剪贴板，不注册全局快捷键。假音频 URL 只在替身之间传递，不读写文件。检查页始终标注“模拟数据”；它的通过只证明组件渲染和受控状态转换，不证明真实麦克风、模型或远程输入成功。

模拟场景允许停留在加载、识别、写入和取消中；切换场景前释放旧替身并等待状态机退出。首次引导场景模拟权限已允许、模型尚未加载，不能替代全新安装的权限弹窗流程。

## 实际 GUI 检查

下表均在 620 点最小宽度、检查窗口内容高度 740 点（包含工具控制栏）下查看真实渲染和辅助功能树。未将这次高度等同正式主窗口最小高度 600 点验收；ContentView 内部自身下限为 520 点。

| 状态 | 深色 / 浅色 | 核对内容 |
| --- | --- | --- |
| 首次引导 | 通过 / 通过 | 三项准备信息可读；模型未就绪时“开始使用”不可用 |
| 日常就绪 | 通过 / 通过 | 快捷键说明、试录/导入、空结果与隐私页脚 |
| 模型加载 | 通过 / 通过 | 加载提示、进度指示、取消可用；录音/导入/复制不可用 |
| 录音 | 通过 / 通过 | 12/60 秒、音量条、停止与取消；导入/复制不可用 |
| 识别 | 通过 / 通过 | 识别说明与进度；取消可用，无重复启动入口 |
| 写入 | 通过 / 通过 | 目标名称、写入/清理说明、长文字；复制不可用 |
| 取消 | 通过 / 通过 | 持续进度说明，没有第二个取消按钮 |
| 长结果 | 通过 / 通过 | 数字、网址和路径换行；复制与保留录音操作可见 |
| 空识别 | 通过 / 通过 | 明确无文字及重试指引、保留录音，复制不可用 |
| 目标失效 | 通过 / 通过 | 长错误换行、目标提示、复制/明确重新粘贴和录音恢复 |
| 剪贴板恢复失败 | 通过 / 通过 | 明确粘贴已发出并提示先检查，结果保留，未误报模型错误 |
| 模型失败 | 通过 / 通过 | 加载失败及重新加载入口，空结果不提供复制 |

目标失效场景另检查 820 点宽度，内容正确重排。长结果展开只读原文后，页面滚动到原文区域；正文与原文内容均可读。辅助功能树能区分忙碌状态下按钮是否可用。本次 Tab 操作没有观察到明确焦点移动，未记为键盘矩阵通过，也没有修改系统键盘偏好。

界面按钮链路：首次引导中点击“加载模型”后，“开始使用”变为可用；进入日常界面后点击“试录一段”→“停止并识别”，出现模拟长结果和一条保留录音；点击“复制”后状态变为“已复制”，保留录音入口消失。此链路使用内存替身，系统剪贴板未被修改。

没有发现被检查画面的内容重叠或关键操作截断。最初下拉菜单在 CUA 控制期间反复失去展开状态，新增开发工具“上一个/下一个”后完成矩阵；一次写入状态截图暂时空白，重新读取同一进程即正常。未将这两次工具观察异常归因于产品缺陷。
