# 0.1.16（18）发布验证

日期：2026-10-20。发行目标：Developer ID 签名、Apple 公证的 macOS arm64 DMG，经 GitHub 正式 Release 分发。最低系统 macOS 15。

## 改动范围

- 识别和润色合并至「语音与润色」，分别选择本地或云端服务，润色菜单提供「不润色」。
- 选择服务商后直接填写密钥并「保存并使用」，取消独立的添加、管理和启用流程；模型、地址等选项收进高级设置。
- 同一家内置服务商的识别、润色可复用已保存密钥；不同服务商、自定义或改变后的地址不会自动复用。
- 保存失败保留原有选择；删除正在使用的连接需确认，删除成功后切回本地模式。
- 底部版本号与处理模式说明共用文字起点，图标独立对齐。
- 四种翻译、首次引导及安装说明同步更新。现有服务选择、密钥与用户设置继续保留。
- 从隔离发布分支构建，不包含主工作区的小米遥控器实验、私人测试材料和宣传视频工程。

## 功能验收范围

简化开发版已实际检查普通服务商密钥填写、掩码、保存按钮状态、高级设置、无默认模型服务商的必填项，以及「不润色」与重新启用原有服务。取消测试编辑没有保存假密钥，原有硅基流动配置保留。

本次没有重新进行麦克风到跨应用写入的完整验收，也没有逐家用真实账户调用全部服务商；不将协议测试视为这些场景的验证。
