# VoxInk 架构复盘落地计划

> **For agentic workers:** Use superpowers:subagent-driven-development for independent document work; complete dependent code and verification in this session. Do not commit or push.

**Goal:** 将已批准的架构复盘落实为一致的合同、可验证的模型入口和提前开展的 UU 验证流程。

**Architecture:** 保留原生 App 和独立推理边界。先完成离线小样与固定文字粘贴验证，再验证 Worker，组装闭环，最后正式选型；预览、分块和润色后置。

**Tech Stack:** Swift 6、Swift Testing、CryptoKit、现有 speech-swift/Qwen3ASR；Markdown。

## Global Constraints

- macOS 15 及以上，Apple Silicon；M5/16GB 才能产生正式验收结论。
- 不自动提交、不推送；私人音频、转录结果、模型和构建缓存不入库。
- 模型下载是唯一默认网络行为；不增加遥测。
- 不在未确定的远程输入框自动发送测试文字。
- 用户已批准复盘建议，无需重复请求文档或可逆代码修改许可。
