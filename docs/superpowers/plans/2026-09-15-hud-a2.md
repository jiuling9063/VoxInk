# A2 HUD Implementation Plan

**Goal:** Install the user-selected A2 outward pulse with the approved ink-teal background and compact capsule.

**Architecture:** A pure sample function computes the mirrored bar height and intensity. SwiftUI Canvas renders 29 bars in a 156 by 36 drawing area inside the existing 180 by 44 nonactivating panel. Processing and error states retain their existing lifecycle.

**Tech Stack:** SwiftUI Canvas, TimelineView, AppKit, Swift Testing.

## Constraints and approved design
- Background #091416 opaque; primary teal #60E0CA. No per-phase color palette change.
- A2 uses front = (time * 0.55 mod 1) * 1.95 - 0.38, Gaussian width 0.17, outward mirrored propagation, height and brightness tied to the same crest.
- Silence retains a visible low baseline. Reduced motion freezes propagation and avoids rapid volume animation.
- Keep nonactivation, target handling, recording and paste behavior unchanged. Error state keeps extra room for recovery text.
