# 自动润色后写入

用户已确认：在设置页面选择是否自动润色；默认关闭。开启后松开快捷键先识别、再润色、最后只写入一次，不再手动点击预览。

## 实现

- `AppStore` 在识别开始时固定本次润色选择，在已有可取消的识别任务中等待模型；进入写入前检查会话标识及取消状态。
- 设置在忙碌时不可改动。使用独立持久化键 `automaticPolishingEnabled`，旧的手动预览开关不自动升级为自动写入授权。
- 失败、超时、校验拒绝及空结果回退到基础文字处理后的结果；取消整次任务不写入。原始识别文字保留，历史记录与最终写入一致。
- 窗口录音及音频导入同样自动处理，但继续只展示结果，不向其他应用自动粘贴。
- 移除手动预览控制；设置显示“自动润色后写入”，处理浮层显示“润色中”。
- 继续使用现有内容保护，只修复合法去重复被相似度比例误拦截的问题，不开放任意改写。

## 四档模型（用户追加确认）

- 轻量：Qwen3 1.7B 4-bit，约 1 GB。
- 均衡（默认推荐）：Qwen3 4B Instruct 2507 4-bit，约 2.3 GB，复用已安装版本。
- 中量：Qwen3 8B 4-bit，约 4.6 GB。
- 最佳效果：Qwen3 14B 4-bit，约 8.3 GB，效果优先定位，建议 24 GB 以上内存，不保证所有文本都优于其他档。
- 固定模型仓库 revision，按需下载并逐文件校验后才发布 ready 标记。取消保留可续传的部分文件；选择档位不自动开启润色、不自动下载、不修改当前会话的模型。
- 共用已有本地 Python/MLX 环境；本版本不负责从零安装 Python 运行环境。缺失时安装提示失败，润色回退原文。
- 三个 Qwen3 混合思考模型使用 `enable_thinking=False`，避免输出思考内容。

模型来源：[1.7B](https://huggingface.co/mlx-community/Qwen3-1.7B-4bit)、[4B](https://huggingface.co/mlx-community/Qwen3-4B-Instruct-2507-4bit)、[8B](https://huggingface.co/mlx-community/Qwen3-8B-4bit)、[14B](https://huggingface.co/mlx-community/Qwen3-14B-4bit)。
