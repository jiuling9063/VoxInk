# 雾光细化 v3

用户反馈：主窗口松散、缺乏秩序；HUD 在保证文字识别的情况下继续轻盈化。

## 主窗口

主窗口分为三层：标题栏（设置入口）、内容区（输入与结果）、底栏（低频引导入口）。内容区使用统一的 24 px 左右边距，窄屏 20 px。输入组内间距 14 px，输入与结果之间 20 px，用一条细分隔线区分任务阶段。

快捷键和录音按钮在同一行左右对齐，避免按钮游离。最近结果拥有清晰标题、独立阅读底色，识别原文与复制/再次写入组成紧贴结果的工具行；反馈置于工具行下方。标题栏设置入口和底部引导不再占用主要操作位置。取消旧的 430 px 强制最小内容高度，内容自然决定窗口高度，不通过增加装饰卡片填充空间。

保留所有演示入口及其既有行为。文本区最小高度 94 px 以容纳短段落，长内容自然增高，超长连续字符允许折行；原文展开仍在正常文档流内，不使用遮罩浮层。窄屏工具行可以换行。

## HUD

| 项目 | v2 | v3 |
| --- | --- | --- |
| 常态外框 | 约 304 × 64 | 约 288 × 56 |
| 状态文字 | 12 px | 13 px |
| 辅助文字 | 10 px | 11 px |
| 玻璃透明度 | 28% | 32% |
| 圆角 | 19 px | 17 px |
| 底缘光 | 2 px | 1 px |

继续减重主要来自留白、波形占宽、投影与边框，不靠缩小文字。文字本身保持不透明，光晕降低中心覆盖，阅读区保留局部深色遮罩。失败提示仍可增高，恢复操作保留可点击尺寸；窄屏优先隐藏计时，保留 Esc 取消入口。

声波与状态光效沿用 v2，减少动态和减少透明度回退保留。透明玻璃在复杂真实背景上的可读性尚需实际评审；这里的尺寸是 CSS 100% 缩放参考，不代表已实测的原生 pt 尺寸。

## 文件与验证

- `main-window.html`：新的主窗口片段。
- `refinement.css`：本轮布局与 HUD 样式增量。
- `build-preview.py`：基于保留的 v2 生成单文件 `index.html`。
- `verify-preview.cjs`：沿用并补充结构与模拟 DOM 检查。

```sh
python3 docs/design-light-tech-v3/build-preview.py
node docs/design-light-tech-v3/verify-preview.cjs
```

浏览器工具此前阻止自动访问本地文件，此次不绕过限制。模拟 DOM 可验证入口与状态逻辑，不能证明真实布局、字体、焦点与透明合成效果。页面需实际打开确认。本轮不修改原生 App 或 Logo，前两版保留以便比较。

本轮检查通过：单文件生成、HTML 嵌套、入口分组、主窗口录音/设置/取消，以及原有流程、光感参数和减少动态的模拟 DOM 回归。实际浏览器视觉验收仍待确认。
