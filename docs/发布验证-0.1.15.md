# 0.1.15（17）发布验证

日期：2026-10-20。发行目标：Developer ID 签名、Apple 公证的 macOS arm64 DMG，经 GitHub 正式 Release 分发。最低系统 macOS 15。

## 改动范围

- 通用 API 连接管理，转写和润色分别选择服务；保留本地模式与现有用户配置。
- 润色提供 10 家主流服务商预设，文件转写提供硅基流动、OpenAI、Groq；两种用途均支持自定义接口。
- API Key 保存在钥匙串；连接编辑支持明确的输入框、焦点提示、密钥掩码和粘贴按钮。
- API 取消、超时、错误分类与润色原文保护；词典、字形转换及写入检查继续生效。
- 词典和设备名称输入框同步改进，四种翻译及麦克风用途说明更新。
- 本次发布从隔离源码构建，没有纳入主工作区的小米遥控器实验代码、私人测试材料或宣传视频工程。

- Release 配置完整串行 Swift 测试：UI 212 项中 2 项按条件跳过，Core 123 项全部通过，合计 333 项通过。

## 功能验收范围

开发版已实际检查全部服务商菜单、用途筛选、密钥输入及掩码、Tab 切换、换服务商清空未保存密钥，以及中文词典输入；取消编辑保留原配置。
