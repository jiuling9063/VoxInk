# 语落 VoxInk 0.1.10 邀请试用版

App 0.1.10，构建 12。Apple Silicon Mac，macOS 15+。

App 已完成 Developer ID 签名与 Apple 公证（Accepted），并附加公证票据。这不代表已经通过 Mac App Store 审核。

## 本次更新

- 自定义快捷键：保留三个推荐组合，可录制自己的快捷键；常见系统冲突会提示，注册失败会恢复原组合。
- 界面支持简体中文、繁体中文、英语、日语、韩语，以及跟随系统。入口为「文字与词典 → 语言」或偏好设置，重新打开 App 后生效。
- 语音支持自动检测和手动指定普通话、粤语、英语、日语、韩语，共用本地模型，不需逐种下载环境。
- 中文输出可选择简体、繁体或保留原样；其他语言不经过中文简化。词典保存和润色后保留专有词的指定字形。
- 复查小窗口中的多语言导航、标题和选择器，调整侧栏宽度，减少标题换行。HUD 的润色阶段判断不再依赖中文提示语。
- 模型下载限定为明确的数据文件，禁用远程代码加载；基础快捷键注册与可选远程事件兼容分离。
- 保留通用远程应用配置、CSV 词库导入导出和内置 Python/MLX 运行组件。

## 安装

退出旧版，将安装盘内的 VoxInk 拖入「应用程序」并替换旧版。已有模型、词库和偏好继续保留。仅在首次使用或切换到未安装模型时下载模型，识别和润色在本机执行。

## 验证与已知边界

本版功能源码已通过 278 项 App 测试，1 项需下载模型的集成测试跳过；40 项 Python 润色测试、4 项 worker 协议测试和1项语言映射测试通过。五种语言分别完成指定与自动检测，共10次本地合成语音识别。这里记录的是功能验证基线，不将版本号更新算作重新运行全部测试。

- 日语样句出现「会議 → 開議」同音词误识别；真人口音、混合语言与不同机型还需试用。
- 外语和粤语润色较保守，主要整理标点、空格及句首大小写；若校验发现字词或语言变化，会保留原文。
- 自动检测对极短句、全汉字日语和方言可能存在歧义，建议手动指定语言。
- 远程配置提供通用粘贴方式，不代表已验证所有远程软件与远端系统；远程工具需开启剪贴板同步和相应按键转发。
- 这是直装试用版，尚未通过 Mac App Store 审核。

详细记录见仓库 `docs/多语言验证-2026-09-22.md`；上架待办见 `plans/app-store-feasibility.md`。
