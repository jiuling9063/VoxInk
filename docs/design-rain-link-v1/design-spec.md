# 雨落·相连 · 独立意象对照

用户最新反馈：不喜欢浅杏色几何 Logo，希望回到雨落的意象，用蓝色或青色，有立体感，并表达这台电脑与另一台电脑的连接。毛笔和琥珀色不采用。

本轮以一颗立体雨滴为主体，下方两处连接的水纹抽象表达两端。采用雨蓝、青色的水光折射，页面与 HUD 回到已验证交互结构的冰青玻璃视觉语言；不新增实际设备连接功能，不更改“语落 VoxInk”名称。

连接的含义是设计解释，不保证用户只看 Logo 就能读出两台电脑。当前水纹细节较多，小尺寸辨识和单色资产仍需专门简化；位图边缘与安装图标资产也需后续精修。本稿尚未确认，不替代已定稿科技版。

文件：`index.html` 为自包含离线页；`assets/logo-rain-link-v1.png` 为内置 imagegen 原始输出；`prompts.md` 保存完整提示词；`build-preview.py` 基于未修改的科技版 v4 构建；`verify-preview.cjs` 检查既有演示交互。

```sh
python3 docs/design-rain-link-v1/build-preview.py
node docs/design-rain-link-v1/verify-preview.cjs
```

保留 HUD 约 288 × 56、13 / 11 字号、58% 背景透明度、完成边缘光一次和减少动态模式。没有修改原生 App。浏览器工具此前禁止自动访问本地文件，因此只检查生成、资源和模拟 DOM 逻辑；真实视觉与玻璃合成待用户评审。
