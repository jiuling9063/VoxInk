# 语落 VoxInk 0.1.0 邀请试用版

发布包标识：0.1.0-trial.1（2026-09-12）。App 内版本为 0.1.0，构建号为 1。

此版本已完成 Developer ID 签名和 Apple 公证。仅供小范围试用；另一台 Mac 的首次安装、模型下载和系统授权仍需验证，不代表已完成跨设备验收。

## 安装

1. 使用 Apple Silicon（M 系列芯片）Mac，系统为 macOS 15 或更高版本；此包不支持 Intel Mac。
2. 解压发布包，退出已运行的 VoxInk，将 VoxInk.app 拖入“应用程序”文件夹。已有版本时先保留备份，避免同时运行多个副本。
3. 从“应用程序”打开 VoxInk。首次使用按界面提示下载识别模型，约 713 MB；需要联网并预留磁盘空间。完成后识别在本机进行。
4. 点击录音，允许麦克风访问。使用跨应用文字写入时，按 App 引导在“系统设置 → 隐私与安全性 → 辅助功能”中允许 VoxInk。
5. 若系统要求退出后重新打开，请照做。在模型就绪后试录一句话，再在文本编辑器的空白文档中测试文字写入。

不要通过关闭系统安全功能解决启动问题；请记录提示并反馈。

## 试用内容

- 先使用默认识别功能；快捷键和录音模式以 App 当前设置为准。
- 在文本编辑器、浏览器和常用聊天软件中验证一次录音只写入一次。
- 在录音或识别完成前按 Esc，检查是否取消；文字已经写入后，Esc 不负责撤回，请使用目标应用的撤销功能。
- 测试休眠唤醒、退出重开，以及连续使用后的响应速度。
- 润色是可选功能。独立润色运行组件不包含在本包中，干净机器暂不将润色作为验收项。

## 已知限制

- 同音词、人名和数字仍可能识别错误，请检查重要内容。
- 不同应用的文字写入兼容性、升级后的权限保持，以及其他机型表现仍在验证。
- 开发机 Gatekeeper 处于关闭状态；签名、公证票据已独立验证，但默认安全设置下的全新安装需要试用者确认。
- 本包没有自动升级安装流程；更新时退出旧版，再替换同一安装位置的 App。

## 隐私与反馈

语音识别在本机执行；下载模型需要网络。无需为了反馈提交私人录音、聊天内容或凭据。请用不含隐私的短句复现问题，并使用随包反馈模板记录系统版本、操作步骤和结果。

建议连续试用一周。优先反馈无法启动、无法录音、错误写入、重复写入和取消失败；然后记录识别后的修改量，以及是否比打字省时间。

App 内附带 ThirdPartyNotices.txt。模型另行下载，本包不包含模型权重。
