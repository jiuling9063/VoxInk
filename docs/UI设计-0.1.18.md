# 0.1.18 界面复核

日期：2026-10-26。依据 justskill 改版设计，将青绿、深灰、圆角卡片与现有 Logo 落到原生 SwiftUI。保留本地与 API 两种模式，不更改识别、润色、快捷键、写入或录音保留策略。

## 页面

- 工作台：主操作卡、结果卡与数据处理说明分层。结果区切换「整理结果 / 识别原文」，「复制结果」始终复制整理结果；重贴提示直接显示，提醒确认重复文字。
- 历史与统计：共用历史列表表面，强调时间、文字与复制操作；统计维持本次启动的非空识别次数与字符数，不将其表述为写入成功数。
- 语音与润色：用步骤编号区分两项设置，服务、模型名称和测试操作分行，长模型名可换行。
- 快捷键与输入：突出当前组合键，分别展示麦克风、文字写入权限，远程工具仍有独立折叠入口。
- 文字与词典：足够宽时三列语言选项、词条对照与并排预览；窄窗口改为纵向布局。保留 CSV、匹配规则、字符限制、编辑和删除。
- 使用方法：三个步骤独立成卡，常见问题显示答案；完整数据保留说明仍可展开。
- 录音浮层：统一底色和边框，保留现有波形、尺寸、非激活行为及取消提示。

## 复核与修正

- 实际检查简体中文、英文、深色与浅色，以及 660 点最小窗口和正常窗口。
- 操作检查包括长结果切换、词典添加和预览纠正、录音中按钮禁用与取消、页面切换。
- 修正设置页沿用上一页滚动位置的问题；切换页面从顶部开始。
- 修正预览左右框高度不齐、结果区旧文案与原文切换入口不一致，以及英文品牌重复显示。
- 主阅读文字、青绿文字与主按钮文字在两种外观下均通过 4.5:1 对比度回归测试。
- 英语、日语、韩语、繁体中文翻译资源与占位符检查通过；日语、韩语、繁体中文未逐页人工验收。
- justskill 改版源文件复核为 0 errors / 0 warnings。设计源稿与原 App 参考截图留在本地设计目录，不将带有本机会话内容的截图上传。
