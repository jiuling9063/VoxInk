# 语落 VoxInk 0.1.9 邀请试用版

App 0.1.9，构建 11。Apple Silicon Mac，macOS 15+。

## 本次更新

- 本地粘贴按键发送后立即完成状态反馈，原有 1.2 秒剪贴板保留在后台执行；下一次粘贴和退出仍等待安全清理。
- HUD 复用窗口内容、合并重复状态刷新；远程设备识别不再遍历辅助功能子树。

- 快捷键、操作方式、模型选择等改为紧凑靠右控件，窄窗口允许上下排列。
- 快捷键与输入 → 远程工具 → 添加远程工具：选择已安装的应用，分别设置 Command+V 或 Control+V。配置按应用保存，不限制品牌。录音开始时锁定本次粘贴方式。
- 远程配置共用剪贴板同步等待档位，普通本地应用不受影响。已有设备配置迁移保留，设备覆盖仅匹配窗口标题。
- 页面和偏好分类即时切换；开关保留读屏名称；录音浮层明确显示准备、识别、润色、写入和取消阶段。
- 减少动态效果时波形固定位置，亮度继续反映音量，读屏提供音量百分比；历史复制反馈跟随对应条目；词库保存与导入显示进行中状态。

## 远程兼容边界

本次提供通用配置与按键投递能力，不代表已经完成所有远程软件的端到端认证。远程工具需开启剪贴板同步，并允许相应粘贴键转发。一个应用连接不同系统时手动切换配置；录音期间保持同一远端会话。普通应用配置不会自动判断远端操作系统。已有兼容处理保留，新工具按各自的应用配置投递按键。

若快捷键被远程工具占用，可更换语落快捷键，或在工作台录音后手动复制。网页远程桌面建议手动复制，避免应用级规则影响浏览器其他页面。

## 安装与验证

退出旧版，用安装盘中的 App 替换「应用程序」内的 VoxInk。已有模型、词库和偏好继续保留。

260 项常规 Swift 测试通过，另 1 项真实下载测试默认跳过。实测了宽窄窗口、浅深色设置、主要页面与状态、应用文件选择及粘贴配置切换；浮层各阶段和音量无障碍值已检查。远程实际传输组合、VoiceOver 全流程和 Instruments 帧率仍需上架前专项验证。
