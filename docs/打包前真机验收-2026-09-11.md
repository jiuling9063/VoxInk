## Esc 取消失败与修复

用户实测：按住录音，中途按 Esc 再松开，仍新增文字；下一次录音可以正常输入。取消场景记录为失败，不能沿用自动测试的通过结论。

根因：原 GlobalShortcutController 仅注册无修饰键 Esc。用户仍按住 Option 时，实际按键为 Option+Esc，原注册无法覆盖。此前测试直接调用 store.cancel()，绕过了实际快捷键注册。

修复内容：

- 按当前录音组合注册普通 Esc，以及对应 Option、Shift、Control 的全部子组合，覆盖修饰键部分松开的顺序；非工作期间注销全部取消键。
- 任一取消键注册失败时回滚本批注册，不向 UI 报告全部可用。
- 快捷键取消回调同步清除按住录音的松键提交标记，再异步取消任务，防止 Esc 后立即松键先提交。
- 新增修饰键组合覆盖测试，以及取消后立即松键不提交、下一次正常录音可恢复的回归测试。
