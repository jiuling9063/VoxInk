# 语落 VoxInk：安装与使用

适用于 0.1.13（构建 15）和当前直装分发方式。需要 Apple Silicon Mac 和 macOS 15+。

## 安装或更新

从公开的项目 GitHub Releases 下载正式 DMG，无需配置开发环境。

1. 更新前退出正在运行的语落。
2. 打开 DMG，将 VoxInk 拖入“应用程序”；已有旧版时选择替换。
3. 从“应用程序”打开语落，本机模型、词库与偏好会继续保留。
4. 按首次引导允许麦克风；需要写入其他应用时，在“系统设置 → 隐私与安全性 → 辅助功能”（部分系统称“设备控制和数据访问”）中允许语落。
5. 在“转录引擎”下载约 713 MB 的识别模型，等待就绪。

无需另装 Python 或 MLX。首次下载需要联网访问 Hugging Face；完成后可离线使用。如果系统报告文件损坏或无法验证，请重新下载正式包并核对 SHA-256，不要关闭系统安全机制。

## 首次输入引导

首次打开时，按步骤选择「本机输入」「远程电脑输入」或「两者都用」，完成权限和模型准备。仅本机使用会跳过远程配置；选择远程或两者都用时，本轮引导验证的是所选远程会话。

1. 添加本机安装的远程工具，按远端系统选择粘贴方式。
2. 在远程工具的设置或会话工具栏中开启剪贴板同步；如两端分别有开关，都要检查。若工具默认同步且没有独立开关，先确认本机复制的文字可以手动粘贴到远端，再勾选同步确认。语落不能代开或检测这一开关，需要用户确认。
3. 打开可清空的测试输入框，点击「准备测试」，切换到该输入框，按一次当前快捷键写入固定文字。此步不会录音或发送消息。
4. 查看目标输入框，点击「看到了正确文字」后继续。按键已发出不会自动算作测试通过。
5. 按引导试说一句话，确认文字出现在目标输入框后完成。

遇到问题可选择「没有出现或文字不对」，按提示先手动复制测试文字来排查剪贴板，再检查权限、粘贴方式、焦点和快捷键。复制测试文字会替换当前剪贴板。语音步骤还会提示检查麦克风、模型与语音语言。

「稍后设置」会保存步骤并进入工作台，不会标记验证完成；侧栏「首次准备」可继续。已完成的用户可从「使用方法 → 首次准备」重新运行。旧版已完成准备的用户升级后不会被强制打断。更改远程配置会清除旧验证结果，更换远端系统或会话后应主动重新验证。

## 语音输入

- 点选目标输入框，按住 `⌥ Space` 录音，松开后识别并写入；`Esc` 取消，单次最长 60 秒。
- “快捷键与输入”提供其他推荐组合和“自定义…”。与系统或其他应用冲突时换一组。
- 工作台录音及“导入音频…”只展示结果，不自动写入外部应用，完成后可手动复制。
- 处理期间保持同一输入位置。“已发送粘贴”不等于目标应用确认接收；重试前先检查有没有重复文字。
- 出现“无法检查输入框”时，回到目标后重试或手动复制结果。请勿用于密码等安全输入。

## 语言与词库

“文字与词典”可选择界面语言、语音语言和中文输出字形。界面语言重新打开 App 后生效；短句自动检测不准时指定语音语言。润色不会翻译原文。

普通话、粤语、英语、日语、韩语识别共用模型，无需分别下载语言包。

纠正词条用于“常识别错的写法 → 正确写法”，例如“雨落 → 语落”。“词库文件”菜单提供模板、CSV 导入与导出。请优先使用 App 导出的模板格式；导入前预览重复、冲突和无效行，确认后才写入。当前最多 100 条。

词库是识别后的文字纠正，不等于训练声学模型。数字、网址、路径和代码有保护规则，可先用文字预览检查。删除词条尚无撤销，重要词库建议先导出备份。

## 可选润色

默认关闭。在“润色模型”选择模型、下载并开启。润色整理口头词和重复表达；不合格、失败或超时的结果会回退，避免阻止输入。

| 档位 | 约下载量 | 使用侧重 |
| --- | --- | --- |
| 轻量 | 1 GB | 短句与速度 |
| 均衡 | 2.3 GB | 日常输入 |
| 中量 | 4.6 GB | 更复杂表达，等待更久 |
| 最佳效果 | 8.3 GB | 效果优先，建议 24 GB 及以上内存 |

“自动”只在已安装模型中选择，不会自动下载其他模型。响应更快、兼顾、效果优先的等待上限分别为 6、12、30 秒；手动固定模型时，偏好不会让同一模型凭空加速。

冷启动、切换语言和闲置两分钟释放后的首次使用仍可能等待。当前结果可展开识别原文；历史只保留最终文字，不支持逐条原文找回。

## 远程工具

在“快捷键与输入 → 远程工具”按应用添加配置，选择远端适用的粘贴方式：Mac 通常使用 `Command+V`，Windows 通常使用 `Ctrl+V`。远程客户端需启用剪贴板同步。

先用默认稳定档（2 秒）；实际远端持续正常后再尝试更快档位。不同客户端、系统和全屏模式表现不同，通用配置不代表已验证全部客户端。录音期间不要切换远程会话；无法检测到的切换可能将文字发往新的焦点。

若两端同时出现语音输入窗口，先取消额外录音，检查远程工具的快捷键转发设置及远端语音软件快捷键。UU 提供“设置 → 键盘 → 仅控制端响应的快捷键”，但本轮添加当前组合后仍出现远端额外语音浮窗，因此不能保证仅添加规则就能解决，原因仍待排查。本轮已确认 UU 远端 Mac 能收到固定文字和语音结果；不代表没有伴随冲突。

本版引导进入文字测试时可能暂留旧的权限提示；请以权限状态为准，点击“准备测试”后提示会更新。

## 数据与常见问题

- 历史文字保留到退出 App；未完成录音最多一条，有效期 24 小时，运行或重新打开 App 后检查清理。可在工作台主动删除恢复录音。
- 完成写入、成功复制或取消后清理对应录音。音频与文字不上传云端处理。
- 权限失效：检查系统设置的麦克风/辅助功能，返回 App 刷新状态。
- 模型下载失败：检查网络和磁盘空间，通过模型页面重试或“检查与修复”。
- 未收到文字：检查工作台提示和目标应用，复制结果手动粘贴，避免反复触发造成重复内容。
- 润色不理想：核对识别原文、指定语音语言、添加专有词；也可关闭润色。重要姓名、数字和否定语义需人工检查。
