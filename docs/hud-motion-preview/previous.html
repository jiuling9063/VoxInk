01 / RHYTHM

A · 向外舒展的音柱

动态预览

中心先起，两侧依次跟随。波峰升高时亮起，回落时变柔和；声音越大，形状和明暗变化越明显。

选定方向 · 紧凑胶囊 / 明暗联动
02 / WAVE

B · 双向水波

动态预览

把音柱连成柔和曲线，波峰从中心流向两端，边缘轻轻消散。

备选 · 双向水波
03 / RIPPLE

C · 水面涟漪

动态预览

声音像落在水面的雨滴，椭圆环一圈圈向外展开，再逐渐淡去。

涟漪感最强 · 更偏意象
底色更深、更实

墨青底 #091416，降低背景画面对 HUD 的干扰。

青绿色更亮

主色 #60E0CA。保留原有色系，轮廓清楚、不做强烈闪烁。

安静时收拢，说话时展开
