## 方向

轻盈来自低对比环境、足够留白和少量透明材质。科技感集中在声波与 HUD，不在每个控件上重复发光。主窗口使用稳固的阅读底色，语音 HUD 使用高不透明度的深色玻璃。

同一方向内提供三个可切换的细化方案：A 雾光（推荐，平衡磨砂与可读性）、B 清透（更实的底色，减弱光感）、C 浮光（加强 HUD 边缘光和阴影）。它们共用结构、文案与功能。

## Logo

概念为两道汇聚的 V 形声纹与一滴墨，冰蓝玻璃材质。当前轮廓也可能让人联想到叶片，评审时需要判断“声音落成文字”的联想是否足够明确。

当前只有一张原始位图和 132 / 64 / 32 px 展示。还未制作：可编辑矢量母版、去玻璃细节的单色符号、16 / 32 px 菜单栏模板、各尺寸 AppIcon 资产集。正式图标需重新处理外部背景与画布边距，不能直接把概念图当安装包图标。

## 窗口与信息架构

主窗口：准备状态 → 快捷键提示 → 主操作 → 最近一次结果 → 复制、再次写入、原文展开。保留最近结果，不新增持久历史、统计或账号系统。技术诊断在原生实施时仍放在低频展开区；本稿没有设计该区的完整内容。

设置：通用（两种按键模式）、权限与模型（就绪和缺权限提示）、用户词典（添加与删除固定替换）。词典演示数据仅存在页面内存中，刷新消失，不访问真实词典。引导展示全部就绪场景，未完成模型下载/修复全流程的高保真稿。

提案环境的“材质、主题、减少动态、播放流程”控件仅用于评审，不是承诺增加到正式 App 的新功能。

## HUD 状态与动效

| 状态 | 文案 / 表达 | 后续 |
| --- | --- | --- |
| 待机 | 正式使用时隐藏；提案可停留展示就绪外观 | 按下快捷键后显示 |
| 录音 | 正在聆听，音量波形，已录时间，Esc | 松开或第二次按下进入识别 |
| 识别 | 正在识别，柔和呼吸，支持取消 | 完成识别后进入写入 |
| 写入 | 正在写入，不宣称目标已收到 | 按实际结果进入完成或失败 |
| 完成 | 已发出粘贴 | 约 1.5 s 后收起；恢复结果必须来自真实回执 |
| 取消 | 已取消 · 未发出粘贴 | 约 1.2 s 后收起 |
| 失败 | 尚未写入 · 文字已保留 | 停留，提供重试与复制 |

录音基本尺寸约 370 × 80 pt，失败状态允许增高；窄屏需调整布局。出现/消失约 180 ms，声波循环约 850 ms。减少动态时取消波形缩放及呼吸，保留静态声波与状态文字。禁止不确定进度伪装为百分比。

本页自动演示时长人为设定，不是性能测试数据。取消边界在写入前；发出粘贴后不能把取消提示伪装为撤销了目标输入。重试前正式 App 需保留既有焦点校验及避免重复写入规则。

原生 HUD 应不激活、不夺走输入焦点，遵循既有 AppKit 浮层实现。建议靠目标屏幕下方居中并预留 Dock 安全区；具体位置、跨屏/全屏、点击恢复控件后的焦点行为需要原生验证，HTML 无法证明。

## 验证范围与后续

本轮只验证离线资源、脚本语法、静态结构及模拟 DOM 状态逻辑。此前浏览器工具安全策略阻止自动访问本地演示页，因此没有换用其他浏览器、localhost 或自动化工具绕过策略；尚未进行实际浏览器渲染、溢出、焦点和鼠标手势验证。用户可直接打开 `index.html` 查看。
