# 三段真实录音对照（2026-09-08）

这是开发小样冒烟，不是正式选型验收。三段录音均来自用户授权的桌面文件，一次转换为 16 kHz / 单声道 / 16-bit WAV，未裁剪。原文件不变，原始与标准化音频哈希记录在本地忽略的 corpus manifest。人工参考文本仍为 null，不计算 CER。

## 方法与环境

Apple M5 / 16GB，Xcode Beta 27.0。三个候选分别对相同的三段 WAV 做独立新进程 Debug 推理；加载与转录分别计时，音频读取不计入转录耗时。不是同进程热身实验，运行次序也不是正式随机化设计，不能比较为 P50/P95。Qwen 先前已运行过；Whisper 首次运行包含 Core ML / ANE 编译，系统缓存状态不等同。

WhisperKit 0.18.0 / swift-transformers 1.1.6，精确源码依赖在 `benchmark/whisper-smoke/Package.resolved`。模型权重复用固定版本清单；新增分词器文件的固定 revision、大小和 SHA-256 见 `benchmark/whisper-tokenizers.json`。模型和分词器均在加载前后校验。公开的上游分词器接口仍有异常回退下载路径，未完成断网验收。

Whisper 默认计算单元：Mel 为 CPU/GPU，AudioEncoder 与 TextDecoder 为 CPU/Neural Engine，Prefill 为 CPU。中文 transcribe，temperature 0，关闭语言检测，去除特殊 token 和时间戳；其余解码设置沿用锁定版本默认值。缓存校验时间不在 Swift 加载指标内。RSS 是进程峰值。

## 排错记录

初版提前注入 tokenizer，触发上游 `loadTokenizerIfNeeded()` 的早退，跳过多语言状态初始化。表现为 Turbo 输出英文/拼音，Medium 首条空文本。不能据此判定模型质量。已改为配置本地 tokenizerFolder 后走标准模型加载流程，并对多语言状态与中文 token 做运行时检查。

早期 `turbo-three-*`、`medium-three-*` 保留为无效接入证据。有效 Whisper 数据使用 `*-verified-*` 文件。新入口编译通过；Python 文件校验和失败行测试共 7 项通过，覆盖哈希、大小、缺文件、越界路径、符号链接、重复清单，以及拒绝启动推理并保留失败行。

## 有效结果
