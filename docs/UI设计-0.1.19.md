# 0.1.19 界面复核

日期：2026-10-26。依据已确认的文字式控件原型，统一原生 SwiftUI 设置界面；保留青绿色强调色。

## 控件规则

- 选项平时显示当前文字值；移入或键盘聚焦后显示浅底、细边框和箭头，点击打开原生菜单。
- 共用 `WorkspaceMenu`、`WorkspacePicker` 和 `WorkspaceModelField`，不再使用长条分段选择器。
- 识别与润色的云端模型 ID 直接输入；下方仅保留次要文字“可输入自定义 ID”，不显示推荐模型列表。
- 设置页回车或失去焦点时提交；Esc 恢复原值。非法输入不覆盖原配置；保存不改写已有钥匙串条目。
- 首次添加和编辑连接也直接显示模型输入，仍以“保存并使用”提交整份连接配置。
- 只读状态使用文字，保留必要的状态颜色；标题和分组减少装饰与重复说明。

## 覆盖范围

| 界面 | 统一的选项 |
| --- | --- |
| 语音与润色 | 服务选择、模型 ID、润色方式、本地模型选择及使用偏好 |
| 快捷键与输入 | 快捷键、按键操作方式、远端平台、同步等待时间 |
| 文字与词典 | 界面语言、语音语言、中文字形、词库文件菜单 |
| 首次准备 | 使用场景，以及复用的模型、语言、输入控件 |
| 工作台结果 | 整理结果 / 识别原文 |
| 独立偏好设置 | 设置类别，以及复用的设置内容 |

历史、统计、帮助和录音浮层不含上述选择控件，继续使用现有统一主题。

## 验证

- 原生检查 App 使用内存设置、凭据替身和拒绝网络请求的模拟传输，检查过程中没有真实 API 调用。
- 已查看简体中文深色、浅色及 660 点窄窗口；模型页、快捷键页和语言页保存了本地截图。
- 实测模型 ID 输入后回车保存、Esc 取消、空值回退、服务菜单打开连接编辑窗口；实测语言和操作方式菜单选择生效。
- 修正 macOS 无边框菜单样式仍显示固定箭头的问题；使用普通按钮菜单呈现文字状态。
- 修正菜单内嵌 Picker 导致选项不可用的问题，改用显式类型化菜单项；修正窄布局候选视图共享焦点状态的问题。
- Release 自动测试覆盖 ID 清理、两种用途的持久化、密钥不改写、无效及忙碌状态拒绝保存；原有全套回归测试通过。
- 四种翻译资源及占位符检查通过；本轮未逐页人工复核外语界面，未重做 UU 远端录音到落字的真人验收。

原型、模拟界面截图及日志仅保留在本地 `local-tests/ui-controls-2026-10-26/` 与 `output/release-0.1.19/ui-review/`，不上传用户设置或会话截图。
