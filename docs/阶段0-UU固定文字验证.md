# 阶段 0：UU 固定文字验证

- 日期：2026-09-08
- 状态：已尝试工具辅助小样，未完成 App 验收。初次连接错误后，用户打开远程微信文件传输助手并聚焦空白输入框；CUA 一次粘贴后未看到文字，随后单字符按键检查也未显示。未点击发送，结果记为 `AUTOMATION_INPUT_NOT_OBSERVED`，不能据此归因于剪贴板同步或 App 实现。
- 用户指定场景：远程微信。只粘贴到输入框，不发送消息。

## 验证范围

在模型选型完成前，用固定文字单独验证 UU 的剪贴板同步、目标焦点和恢复时间。该实验不证明 ASR、全局快捷键或完整 App 已可用。先确定远程微信的文件传输助手或另一个明确指定的可清空输入框，再执行测试；不得以当前聊天窗口代替已确认目标。

测试文字固定为：`语落测试 S0001：今天 15:30 检查 VoxInk v0.1，金额 128.50 元。`

## 步骤

1. 在本地设置可恢复的测试剪贴板内容，不使用私人数据。先测纯文本，再测图片、RTF 和多 item。
2. 通过 UU 打开远程微信的已确认输入框，记录 UU 版本、连接方式、本地和远程系统版本。
3. 固定文字写入本地剪贴板后，只发送一次 Command+V；不按 Return，不点击发送。
4. 记录本地发出时刻和远端文字完整可见时刻；观察是否重复、缺字或进入错误输入框。
5. 分别试验 0.5、1.0、1.5、2.0 秒的恢复延迟，每档先做 5 次。它们是实验参数，不是已经证明可靠的产品默认值。
6. 每次等待恢复结束后，检查原内容全部类型是否可用，清空远端测试文字，再开始下一次。
7. 加入下表异常场景。不能可靠恢复目标时保留结果供手动复制；不向未知目标自动粘贴。

## 必测场景

| 场景 | 预期 |
| --- | --- |
| 正常文本 / 图片 / RTF / 多 item | 远端一次输入，原快照完整恢复 |
| 快照读取时用户复制 | 丢弃失效快照，不覆盖新内容 |
| 恢复等待时用户复制 | 不恢复旧快照 |
| 快照类型读取失败或超限 | 不自动覆盖剪贴板，保留待复制结果 |
| 恢复等待时再次触发 | 新事务不得被旧恢复回调覆盖；首版可提示等待清理结束 |
| 本地焦点切走 / 目标退出 | 不能确认目标时不自动粘贴 |
| UU 断连 / 重连 / 网络变慢 | 不自动重发，不把本地发送当作远端成功 |
| 本地安全输入开启 | 不发送粘贴 |
