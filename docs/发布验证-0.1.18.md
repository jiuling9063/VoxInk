# 0.1.18（20）发布验证

日期：2026-10-26。目标：Developer ID 签名及 Apple 公证的 macOS arm64 DMG，支持 macOS 15+。

## 范围

将 justskill 改版落实到原生工作台、历史、统计、语音与润色、快捷键、文字与词典及帮助页。兼顾深浅色、窄窗口、长结果和英文文案；保留已有业务逻辑与用户设置。细节见 [UI 设计复核](UI设计-0.1.18.md)。

按用户要求清理主工作区未提交的小米遥控器实验：删除实验实现、测试和文档，撤回蓝牙权限与接管入口。该实验从未进入发布基线，本版不包含这些内容。不修改 SayAll、豆包、UU 或系统蓝牙设置。

## 验证

- 翻译覆盖：4 种翻译各覆盖 609 条源文案，668 条资源及占位符检查通过。
- Release 串行 Swift 测试启用本机 HTTP fixture：346 项通过、5 项需要显式启用的集成测试跳过；覆盖 URLSession JSON、multipart 与重定向拒绝。
- 新增深浅色阅读与主操作文字的对比度回归测试，通过 4.5:1 下限。
- 原生界面检查的场景、交互与边界见 UI 设计复核；本轮不声称已重新完成 UU 远端录音到落字的真人验收。
- 本地测试沿用未跟踪的 noise-regression.wav 素材；不将本地录音、设置、密钥或原始测试报告提交到仓库。

- 正式 App 的 Python / Metal 组件自检通过，42 个原生运行时文件已签名；主程序与本地识别 Worker 均按现有依赖锁重新构建。
